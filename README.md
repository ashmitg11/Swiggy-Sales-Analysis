# 🍔 Swiggy Sales & Restaurant Performance Dashboard

## 📌 Project Overview

This project presents an interactive Excel dashboard built to analyze Swiggy restaurant and food order data. Using Excel's data analysis and visualization capabilities, the dashboard transforms raw data into meaningful business insights related to sales performance, restaurant ratings, customer preferences, and food category trends.

---

## 🎯 Objective

The goal of this project is to analyze Swiggy sales data and provide actionable insights that help understand:

* Overall sales performance
* Restaurant performance and ratings
* Customer ordering behavior
* Popular food categories
* Sales trends and patterns

## 📊 Dashboard Features

### Key Performance Indicators (KPIs)
